Before you start

  1. Keep this file on your own computer. It holds the private decryption key and the answer key, so never upload it to GitHub, the course Team or email.
  2. Open it in Chrome, Edge or Firefox by double-clicking. It works offline.

Marking

  1. In the course Team, open the shared folder telepharmacy, select the students’ files and download them (Teams gives you one zip file). Unzip it.
  2. Drop all the .txt files onto the box on the first tab, or press Choose a folder and pick the unzipped folder. PDFs, Word files and files for the other assignment are ignored or refused with a reason.
  3. To mark a single file instead, open it in Notepad, select all, copy and paste it into the paste box. It is marked as soon as you paste.
  4. The table shows one row per student. When a student submitted more than once, the latest submission is marked and the earlier ones appear in All files as superseded.
  5. Press Details on any row to see every question: the student’s answer, the key and the score.
  6. Press Export to Excel for a workbook with five sheets: Marks, Scores by question, Answers, Item analysis and All files.

Deadline rule (applied automatically)

  1. The time used is the submission time encrypted inside each file. When the student was online, the page took that time from the course website clock (column Clock: Website), so changing the computer clock does not help a student.
  2. On time: full mark. Late day: the mark is multiplied by 0.5. After the late day: not accepted, final mark 0 (the student page refuses these, so such a file signals tampering).
  3. Clock: Device means the page could not reach the website clock and used the student’s device clock. For those rows, compare the time with the upload time shown in the shared folder.

Flags to review

  1. Same work identifier: two students’ files come from one browser or from one shared backup.
  2. Imported a backup made with another ID: the student loaded someone else’s saved work.
  3. Answers almost identical: two students share the same answers, including several identical mistakes.
  4. File name carries a different ID: a file was renamed or belongs to someone else.
  5. Files that were edited, cut short or damaged cannot be decrypted; they are listed under Not marked with the reason.
